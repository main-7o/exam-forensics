# 검증

## 실제 시험 데이터

### 데이터

Cizek & Wollack(2017) *Handbook of Quantitative Methods for Detecting Cheating on Tests*에 수록된 실제 자격시험 데이터를 사용했습니다([공개본](https://cengiz.me/posts/xgboost/)). 4지선다형이며 시험지는 두 종류(각 170문항, 약 1,600명)이고, 문항별 풀이 시간이 포함되어 있습니다. 시험 주관사가 사전 유출 의심자로 분류한 응시자는 94명입니다.

데이터는 저장소에 포함하지 않았습니다. 사용할 때는 위 핸드북을 출처로 밝혀야 합니다. 아래 스크립트로 같은 결과를 재현할 수 있습니다.

```bash
python benchmarks/cizek_wollack.py <train.csv, test.csv가 있는 폴더>
python benchmarks/plant_real.py <같은 폴더>
```

### 주관사 분류와의 비교

주관사 분류를 사용하지 않고 분석한 뒤, 그 결과가 분류와 얼마나 일치하는지 측정했습니다(3,211명).

| 항목 | AUC | 오탐률 1% / 5%에서의 탐지율 |
|---|---|---|
| 답안 공유 | 0.63 | 24% / 29% |
| 이상응답 | 0.61 | 10% / 13% |
| 응답시간 | 0.61 | 1% / 12% |
| 실력 대비 풀이 속도 | 0.77 | 46% / 47% |
| 항목 종합 (순위 최댓값) | 0.92 | 27% / 78% |

같은 데이터에서 주관사 분류로 학습한 XGBoost 모델이 AUC 0.93을 기록했다는 보고가 있습니다(직접 검증하지는 않았습니다).

최종 판정된 응시자는 22명이며, 이 중 12명이 주관사 분류와 일치했습니다. 답안 공유로 판정된 13쌍 가운데 7쌍은 두 명 모두, 4쌍은 한 명만 주관사 분류 대상이었습니다. 한 명만 분류된 쌍의 다른 응시자도 분류 대상자와 같은 오답을 기대치의 약 두 배 공유하고 있어, 주관사가 놓친 공모자일 가능성이 있습니다. 다만 이를 확인할 방법은 없습니다.

### 가상 부정행위 삽입

주관사 분류에 해당하지 않는 응시자들의 실제 응답에 가상의 답안 베끼기와 AI 사용을 1%씩 삽입했습니다. 베낀 문항 비율 70%와 100%, AI 사용 비율 80%와 100% 조건 모두에서 90명 중 90명을 찾아냈습니다. 문항 수가 170개로 많아 정보량이 충분했기 때문입니다. 아무것도 삽입하지 않았을 때는 시험지당 약 2명이 판정되었습니다.

### 실제 데이터에서 발견한 문제

- 응답시간 검사가 처음에는 이론적 카이제곱 분포를 기준으로 했는데, 실제 데이터에서는 정상 응시자의 31%가 p<0.01로 나왔고 1,607명 중 160명이 판정되었습니다. 사람마다 풀이 시간의 변동 폭이 원래 다르기 때문입니다. 실제 응시자 분포의 중앙값과 MAD를 기준으로 바꾼 뒤 p<0.01 비율은 1.1~1.6%, 판정 인원은 1명으로 줄었습니다.
- 주관사 분류 대상자는 점수는 평균적이지만 풀이 속도가 표준편차의 약 1.7배만큼 빨랐습니다. 이를 실력 대비 풀이 속도 지표로 추가했지만, 빠른 쪽 분포의 꼬리가 두꺼워 정상 응시자도 7~8%가 p<0.01로 나옵니다. 따라서 판정에는 사용하지 않고 순위 점수로만 제공합니다.
- 유출 문항 목록 없이 빠르게 정답을 맞힌 패턴의 상관관계로 유출 문항을 찾는 방법도 시도했으나, AUC가 0.38~0.48에 그쳐 제외했습니다.

### 한계

- 주관사 분류는 확정된 사실이 아니라 의심 목록입니다. 분류에 풀이 속도가 반영되었다면 속도 지표의 성능은 과대평가되었을 수 있습니다.
- 데이터에 정답 키가 없어 응답 패턴으로 추정했습니다.
- 분류가 사전 유출에 한정되어 AI 사용 탐지는 가상 삽입으로만 확인했습니다.
- 항목 종합 방식은 두 가지 방식을 비교한 뒤 선택했습니다.
- 데이터셋이 하나뿐입니다.

## 가상 데이터

`simulate.py`는 3모수 문항반응모형, 문항별 오답 매력도, 로그정규 응답시간으로 가상 시험을 만들고 부정행위자를 삽입합니다. 부정행위자를 알고 있으므로 탐지율과 오탐을 정확히 측정할 수 있습니다.

### 오탐

부정행위자가 없는 시험 10회(10만 명)에서 잘못 지목된 응시자는 1명이었고, 고사실 3,580곳 중 잘못 판정된 곳은 없었습니다.

### 탐지율

1만 명 시험에 유형별로 1%씩 삽입했습니다(시드 3개 평균).

| 조건 | 탐지율 | 단순 비교 방식 |
|---|---|---|
| 문항의 50%를 베낌 | 30% | 3% |
| 70%를 베낌 | 65% | 30% |
| 전부 베낌 | 90% | 69% |
| AI를 문항의 50%에 사용 | 10% | 4% |
| AI를 80%에 사용 | 61% | 26% |
| AI를 전부 사용 | 90% | 61% |
| 유출 문항 15개 (8개) | 58% (9%) | |

단순 비교 방식은 같은 오답의 개수만 세는 방식입니다.

AI 사용 시뮬레이션은 AI가 문항마다 선호하는 답이 있고 85% 확률로 같은 답을 낸다고 가정했습니다. 실제 모델마다 다를 수 있습니다.

### 학교 효과

같은 학교 학생들의 공통 오답 경향을 넣어 모형 가정이 어긋나는 상황을 만들었습니다(정상 응시자 3만 명).

| 조건 | 보정 없음 | 학교 보정 |
|---|---|---|
| 학원 30곳, 고사실과 무관하게 배정 | 0명 | |
| 소규모 학원 300곳, 고사실과 무관 | 0명 | |
| 고사실과 학교 일치, 효과 보통 | 0명 | |
| 고사실과 학교 일치, 효과 강함 | 240명, 고사실 169곳 | 0명, 0곳 |

학교와 고사실이 겹치고 효과가 강한 경우에만 오탐이 발생했으며, 이때는 경고가 표시되고 학교 보정으로 해결됩니다. 학교 효과가 없는 시험에서 학교 보정을 켜면 일부만 베낀 응시자의 탐지율이 약 10%p 낮아집니다.

### 고사실 간 공유

0.5%가 다른 고사실 응시자의 답을 베낀 경우입니다.

| 인원 | 전부 베낌 | 70% 베낌 | 오탐 | 검사한 쌍 | 시간 |
|---|---|---|---|---|---|
| 1만 명 | 90% | 44% | 0명 | 5천만 | 10초 |
| 10만 명 | 68% | 22% | 0명 | 50억 | 92초 |

### 시도했으나 제외한 방법
